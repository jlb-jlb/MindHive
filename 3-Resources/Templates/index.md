# Templates

These files describe each note type for an agent that writes the note by hand. They are not insertable in Obsidian, since each wraps its frontmatter and body in code fences under explanatory headings. The insertable counterparts live in the vault-root `_templates/` folder, one file per entry below with the same name minus `-note-template`, and are documented in [Obsidian Insertable Templates](/3-Resources/wiki/obsidian-insertable-templates.md). Keep the two sets in step when a field or section changes.

* [Project Note Template](project-note-template.md) - Template for active outcomes.
* [Area Note Template](area-note-template.md) - Template for ongoing responsibilities.
* [Resource Note Template](resource-note-template.md) - Template for reusable knowledge.
* [Decision Note Template](decision-note-template.md) - Template for choices and tradeoffs.
* [Agent Handoff Template](agent-handoff-template.md) - Template for resumable agent work.
* [Daily Capture Template](daily-capture-template.md) - Template for inbox capture.
* [Daily Note Template](daily-note-template.md) - Template for dated daily journal notes.
* [Wiki Article Template](wiki-article-template.md) - Template for wiki how-tos and topic articles.
